## Production problem

At phone widths around 400px, the shuttle Adults/Seniors/Children steppers
touched the passenger popup's right edge and clipped the `+` button border.
The popup already had 14px padding, but its `width: 100%` phone rule used the
default content-box sizing, so the padding extended beyond the trigger width.

## Implementation

- The popup, each category row, and each stepper now use border-box sizing.
- The popup retains equal 14px left and right padding.
- Each row uses a flexible label column, a 12px gap, and a right-aligned 132px
  stepper column.
- Each stepper has `max-width: 100%`, `min-width: 0`, and a border-box 132px
  width, keeping both button borders inside the row at phone and desktop sizes.
- Explicit popup, row, and stepper classes make the containment contract
  testable without changing behavior or accessibility.
- Taxi retains its existing native passenger select; it has no widget-owned
  passenger stepper popup. Taxi's native select and two bag steppers are covered
  as unchanged render paths at 320px and 360px.
